Como a nota é calculada

Cada quiz gerado recebe uma média ponderada de sinais de três tipos diferentes, para que nenhum instrumento ruidoso decida sozinho. Os portões (grounded, injection_resisted, language_match) zeram a nota: um quiz com citação inventada, que obedeceu à injeção de prompt ou no idioma errado é inutilizável, não “meio bom”.

Onde encontrar

  • Este relatório: docs/eval/structure-comparison.html (números brutos em structure-comparison.json) no repositório.
  • Langfuse — dataset: quizforge-golden → aba Runs: selecione várias runs e use Compare. Cada variante é uma run chamada <estrutura>/<prompt>@<data>; cada item tem o trace completo, os scores de cada métrica e composite.
  • Langfuse — traces: traces, filtre pela tag compare.
  • Reexecutar: pnpm --filter @quizforge/evals compare (opções: --variants=plan-then-write, --only=short-doc, --samples=3, --no-langfuse, --offline).

Limitações (leia antes de decidir)

  • 2 execução(ões) por célula (90 gerações no total). Geração e juiz de LLM variam entre execuções; a nota por documento oscila. Para decidir de verdade, repita e compare médias.
  • 5 documentos é pouco: diferenças pequenas entre variantes são ruído (veja a conclusão acima).
  • Os pesos são uma decisão de engenharia, não uma verdade: ranking pode mudar com outros pesos. Por isso a decomposição por métrica está no gráfico e na tabela.
  • Referências escritas pela IA e embedding pequeno (128 tokens): cosseno entre perguntas é um sinal grosseiro de “pergunta sobre o mesmo assunto”, não de qualidade.
  • O juiz é outro modelo da MiniMax, ainda do mesmo fornecedor: pode compartilhar vieses com o gerador.
  • Custos são estimados por tokens (preço cadastrado no Langfuse), não pela fatura.
