QuizForge is an AI agent that reads a Markdown README (a URL), writes a 5–8 question multiple-choice quiz, lets a user take it in a web app and computes a weighted score. It runs on AWS, is built with Terraform and deployed by GitHub Actions. Every quiz is traced and scored in Langfuse.

Architecture

Everything runs in one AWS region (us-east-2), in two zones, created by Terraform.

PieceWhat it doesWhy this choice
CloudFront + WAF → ALBThe only public entrance: HTTPS, a rate limit of 1000 requests per 5 minutes per IP, managed rules. The load balancer accepts CloudFront onlyNo custom domain was available, so the CloudFront address is the app address
web (Next.js, 2–6 tasks)The pages and a BFF: it keeps the login in an httpOnly cookie and calls the API with the tokenTokens never reach the browser's JavaScript

One quiz, end to end

Creating a quiz (slow, asynchronous)Answering a quiz (fast, synchronous)
StepsAPI validates and saves a queued quiz → SQS → worker generates → quiz is ready → scorer judges it. The browser polls until readyEach answer is saved as it is picked → submit computes the score from what is stored → result with the answer key
Why it is built this wayThe model is slow, costly and can fail, so it gets a queue, a budget and retriesNo model is involved: it is cheap, exact and instant
Safe to repeat?Yes: an Idempotency-Key makes a retry return the same quizYes: answers are upserts guarded by a revision number; submitting twice returns the saved result

Modelling choices that matter

ChoiceWhy
Options in their own table; is_correct on the optionA multi-answer question needs no special structure; the answer key is never sent to the browser before the submit
answer_selections instead of an arrayThe database refuses an option that does not exist, and a score is a plain join
Score per answer and final score, with a scoring_versionThe user sees why; old attempts keep the rule they were scored with
No users tableCognito is the source of truth; every query filters by its sub, and another user's id answers 404
The rules live in the databaseUnique idempotency keys, one active attempt per user and quiz, a monotonic revision per answer, SELECT … FOR UPDATE on submit, checks on ranges

The agent

StepWhat happens
routeNo model call: a short document (up to ~4,500 tokens) goes single-shot; a long one with 4 or more sections goes section-map-reduce, so the questions cover the whole document
generate and checkThe model returns strict JSON (validated by zod, repaired up to 2 times). Fixed checks: every question must carry a literal quote from the document; a question whose quote cannot be found is dropped, never shown
critique and reviseA second pass finds weak or ambiguous questions and rewrites them, at most 2 rounds
saveQuestions and options are written in one transaction, then the quiz is ready
ControlValue
Budget per job16 model calls, 120,000 tokens, 5 minutes; kept in the database, so a redelivered message does not reset it
RetriesModel HTTP 3 retries · JSON repair 2 · critique 2 rounds · queue 3 receives, then the dead-letter queue and an alarm
Resume after a crashLangGraph checkpoints in Postgres: a restarted worker continues without repeating paid calls. They are deleted when the quiz is saved, and after 24 h at the latest
ModelsGenerator MiniMax-M2.7, judge MiniMax-M3 (a different model, to reduce self-preference); both through one OpenAI-compatible client

Score

LevelFormulaWhere it is stored
One question4 × max(0, (hits − misses) / K), K = number of correct options (a single-answer question is 4 or 0)answers.score
Weight of a question1.1^(position − 1): each later question weighs 10% moreanswers.weight
Final score (0 to 4)Σ(weight × score) / Σ(weight); percentage = score / 4attempts.final_score
No AI in the score
The score is computed by the server from the stored answer key and selections (packages/core/src/scoring.ts), with table and property-based tests. The LLM judge grades the quality of the quiz, never the user's answers.

Security and guardrails

Eight layers, from the edge to the data. A threat is stopped by the first layer that can see it.

QuestionAnswer
Can a user read another user's quiz?No. The identity is the sub of a verified Cognito token (signature, issuer, expiry, client); the API reads nothing else. Every query filters by it, and a foreign id answers 404. A test tries it
Can someone flood the site?Layers: WAF (1000 per 5 min per IP), 120 requests a minute per user, 10 quiz creations a minute, 10 quizzes a day, a queue that limits model calls. Not covered: a distributed attack from many IPs
Can the README URL point anywhere?No. Only https to github.com and raw.githubusercontent.com; the name is resolved and private addresses are blocked; redirects are re-checked; 10 s and 512 KB limits
What if the README contains a prompt injection?It is treated as data: hidden or encoded text is rejected, only English, Portuguese and Spanish are accepted, the document is delimited in the prompt, and the reply must be only the quiz JSON with a literal quote. Output rails check it. A public benchmark of 500 samples measured the first layer honestly (modest recall, no false positives)
What about CORS and CSRF?No CORS: the browser only talks to its own origin and the BFF holds the cookie; the BFF blocks cross-site requests

Main decisions

DecisionInstead ofWhy
Four separate services and a queueOne server calling the model in the requestA slow, paid, failing step is isolated; the API stays fast; concurrency is capped
The judge runs after the quiz is ready (scorer)Judging before savingThe user waits ~30 s less, and a judge failure never loses a quiz
Score in plain codeAn LLM grading answersExact, free, testable; the model only grades quiz quality
PostgreSQL for data and checkpointsRedis for checkpointsNo extra service (about US$12 a month); the same effect with a delete on success and a 24 h sweep. Redis is a listed future step
Prompts in Git, pushed to Langfuse only by the pipelineEditing prompts in the Langfuse UIA prompt cannot reach Langfuse without passing the gates
Real-model evaluation on PRs that need itOn every PR, or only after the mergeQuality blocks the merge, and a PR without prompt or LLM changes costs nothing
CloudFront address, no domainA domain and certificateNo domain available
