# Biblioteca Aurora

A Biblioteca Aurora é uma ferramenta de código aberto para gerar relatórios a partir de planilhas.
Ela foi criada por uma equipe de engenheiros brasileiros e é distribuída sob a licença MIT.

## Instalação

Para instalar, basta executar o comando de instalação do gerenciador de pacotes e importar o módulo no projeto.
A versão mínima suportada do Python é a 3.10, e versões anteriores não recebem correções de segurança.

## Formatos de saída

A biblioteca gera relatórios em PDF, HTML e Markdown.
O formato PDF usa um modelo de página configurável, com cabeçalho e rodapé personalizados.
O formato HTML inclui uma folha de estilo embutida, o que dispensa arquivos externos.

## Desempenho

Planilhas com até cem mil linhas são processadas em menos de dez segundos em um computador comum.
Para arquivos maiores, a Aurora lê os dados em blocos para manter o uso de memória baixo.

## Contribuição

Toda contribuição deve incluir testes automatizados e passar pela revisão de pelo menos um mantenedor.
As discussões acontecem no fórum público do projeto, que é moderado pela comunidade.
